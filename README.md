# GYM RATS

A dark, hardcore workout landing page with the supplied Spotify playlist embedded directly into the site.

## Spotify playlist

https://open.spotify.com/playlist/4vamsXSANnzcCQYcgglhha

The site uses Spotify's official Embed player, so you do not need to upload or host MP3 files yourself.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The generated `dist` folder can be deployed to Vercel, Netlify, Cloudflare Pages, GitHub Pages, or another static host.
